How it stays secure

Built with the assumption that documents are private.

HttpOnly session cookies

Your session token is never exposed to JavaScript, which closes off the most common way tokens get stolen through malicious scripts.

Password hashing, not storage

Passwords are hashed with bcrypt before they ever touch the database — your actual password is never stored, anywhere.

Strict per-user isolation

Every document, chunk, and query is scoped to your account at the database level, not just hidden in the interface — other users' files are structurally unreachable from your account.

No ID guessing

Requesting a document that isn't yours returns the same "not found" response as one that doesn't exist, so document IDs can't be probed to discover what other people have uploaded.

Validated uploads

Files are checked by both extension and file signature, and capped in size, before anything is written to disk.

Grounded answers

The question-answering assistant is instructed to answer only from the excerpts retrieved from your documents, and to say so plainly when it doesn't have enough information.
